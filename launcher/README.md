# Launcher source

This directory contains the native SwiftUI application, unit and provisioning
tests, application resources, the minimal emulator host, and release metadata.

Use the repository-level commands and documentation:

- [Build and validation](../docs/building.md)
- [Architecture](../docs/architecture.md)
- [Release process](../docs/releasing.md)
- [Contributing](../CONTRIBUTING.md)

Private game APK inputs, downloaded Android components, Sparkle build cache,
compiled apps, and disk images are intentionally excluded from Git.
